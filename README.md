🎨 Drawing a Little — Sitio de Ilustraciones

📌 Descripción del proyecto

Drawing a Little es un sitio web artístico creado para presentar tu contenido de ilustración, tus videos de dibujo y tu marca personal como artista digital.
Este proyecto combina:

  ✏️ Ilustración y estilo visual personalizado
  🎥 Enlaces directos a tus videos de YouTube
  🌗 Tema claro/oscuro dinámico
  🧭 Navegación lateral mediante sidebar animada
  📬 Formulario de sugerencias
  📱 Diseño responsive para celulares y tablets

El objetivo del sitio es ofrecer una experiencia visual atractiva, cómoda y accesible para quienes quieran aprender o seguir tu contenido artístico.

🌐 Demo en vivo

🔗 https://gerardomorel.github.io/Mis_Ilustraciones/

⭐ Características principales:

  🎞 Galería interactiva con miniaturas que enlazan a tus videos de YouTube.
  🧭 Sidebar animada que se expande al pasar el mouse.
  🌙 Modo Oscuro / Claro con transición suave.
  📄 Secciones bien organizadas: “Videos”, “Sobre mí”, “Contacto”, “Sugerencias”.
  📩 Formulario de sugerencias para recibir ideas o pedidos de tus seguidores.
  🎨 Estilo visual inspirado en bocetos y texturas artísticas.
  📱 Diseño totalmente responsive.
